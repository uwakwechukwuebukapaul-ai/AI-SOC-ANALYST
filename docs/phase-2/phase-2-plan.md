\# Sentinel DNA Phase 2 Plan



\## Phase Objective



Transform Sentinel DNA from an incident detection platform into a complete SOC analyst investigation platform.

\# Phase 2 Modules

Provide analysts with a central location to investigate security incidents.

\- View active cases

\- View severity

\- View evidence

\- View timeline

\- Add analyst notes

\- Update case status

\- Assign investigations
